# 🚤 ボートレース予想アプリ

[Boatrace Open API](https://boatraceopenapi.github.io/) の本日の出走表データを使い、
ブラウザだけで動く（バックエンド不要の）ボートレース自動予想 Web アプリです。
スマホでもそのまま使え、ホーム画面に追加すればアプリのように起動できます（PWA対応）。

## 特長

- **インストール不要** — URL を開くだけ。スマホ／PC 両対応のレスポンシブUI。
- **本日のレースを自動取得** — 開催中の全24場・各レースの出走表をリアルタイム取得。
- **直前情報を反映** — **実際の進入コース・展示タイム・展示ST・チルト・天候/風/波/気温/水温**を
  予想に取り込みます。特に進入隊形の変化（前付け）と展示タイムは的中に直結。
  - 締切前の展示は、付属の **直前情報サーバー（Cloudflare Workers / `worker/`）** を無料デプロイして
    アプリの ⚙️ に登録すると、公式サイトから自動取得します（オープンAPIは過去レースのみ反映のため）。
- **Claude流の分析予想** — 各艇のコース取り（戦法）と全指標を分析し、◎○▲△の印と
  「なぜそう読むか」の所見コメント、レース総評を自動生成。
- **厳密な確率計算（乱数なし）** — Plackett–Luce の閉形式で各艇の1着/2着/3着確率と
  3連単(1着-2着-3着)の確率を数式で正確に算出します（モンテカルロ抽選は不使用）。
- **勝ちに最も近いフォーメーション** — 算出した3連単確率から、点数あたりの的中率が
  最大になる買い目（効率フロンティア）を「絞り／標準／手広く」で提案。各案の的中率と
  必要金額を表示します。
- **PWA** — ホーム画面に追加してフルスクリーンのアプリとして利用可能。

## 使い方

1. 公開 URL（GitHub Pages）をスマホ／PCのブラウザで開く
2. 「会場」と「レース」を選ぶ
3. 「予想する」をタップ

## 公開方法（GitHub Pages）

このリポジトリには Pages 自動デプロイ用のワークフロー（`.github/workflows/deploy.yml`）が含まれています。

- 対象ブランチ（`claude/zen-hawking-0ed2tx` または `main`）に push すると自動でビルド・公開されます。
- 初回は GitHub の **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください
  （ワークフロー側でも `enablement: true` により自動有効化を試みます）。
- 公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## 仕組み

**0. 直前情報の取得** — `previews/v2/today.json` から進入コース・展示タイム・展示ST・
チルト・気象を取得（あれば）。**枠番ではなく実際の進入コース**で有利度を評価し、
**展示タイム**をレース内で相対評価して加点、展示STの鋭さも反映します。

**1. 強度モデル（実データで最適化）** — 過去レースのバックテストに基づく
「**コース基礎1着率 × 能力**」の積モデル:

```
強度 w = COURSE_BASE[進入コース] × exp(BETA × 能力のレース内偏差z)
```

- `COURSE_BASE` … 進入コース別の実測1着率（1コース=0.596 … 6コース=0.016）。
  ボートレースは進入コースが最大の決定要因なので、これを土台にする。
- 能力指数 … 全国/当地の勝率＆2・3連対率、平均ST、モーター・ボート、級別を統合（F/L減点）。
  レース内で標準化し、コース基礎を上下させる。
- 直前情報があれば、展示タイム・展示STをレース内で相対評価して能力にブレンド。

`BETA`（能力の効き）と直前ブレンド`W_PRE`は、実データ715レースのバックテストで
3連単フォーメーション的中率が最大になるよう調整（`app.js` 冒頭で変更可）。

**2. 確率を厳密に計算** — 強度 `w` を用い、
[Plackett–Luce モデル](https://en.wikipedia.org/wiki/Discrete_choice)の**閉形式**で
各艇の1着/2着/3着確率と3連単(1着-2着-3着)の確率を計算します（乱数・シミュレーションは不使用）。

**3. 分析コメント生成** — コース取り・級別・全国/当地成績・ST・モーターなどから
各艇の所見とレース総評を文章で生成します。

**4. 最適フォーメーション選択** — 全候補フォーメーションを算出確率で評価し、
点数あたりの的中率が最大になる「効率フロンティア」から3段階を提案します。

各パラメータ（`WEIGHTS`・`TEMP`）は `app.js` 冒頭で調整できます。

## 注意

本アプリの予想は公開データに基づく自動計算であり、的中を保証するものではありません。
舟券の購入は自己責任で行ってください。**20歳未満は舟券を購入できません。**
