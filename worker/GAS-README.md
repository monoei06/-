# 直前情報サーバー（Google Apps Script 版）デプロイ手順

Cloudflare にサインインできない場合は、**お持ちの Google アカウントだけ**で作れる
こちらの方法がおすすめです。追加のサインアップは不要です。

`gas-proxy.gs` が公式サイトから直前情報を取得して JSON で返す Web アプリです。

> 📱 スマホでも可能ですが、画面が小さいので、可能なら **PCのブラウザ**だと楽です。
> スマホの場合は Chrome のメニューで「**PC版サイト**」にチェックを入れると操作しやすくなります。

---

## 手順

### 1. プロジェクトを作る
1. https://script.google.com/ を開く（Googleにログイン済みならそのまま）
2. 「**新しいプロジェクト**」をタップ

### 2. コードを貼り付け
3. 最初から入っている `function myFunction() {}` を**全部消す**
4. 送った **`gas-proxy.gs` の中身をまるごと貼り付け**
5. 💾（保存）アイコンで保存

### 3. ウェブアプリとして公開
6. 右上の「**デプロイ**」→「**新しいデプロイ**」
7. 歯車⚙️「種類の選択」→「**ウェブアプリ**」を選ぶ
8. 設定を次のように：
   - **次のユーザーとして実行**：`自分`
   - **アクセスできるユーザー**：`全員`  ← ここ重要（「全員」にしないとアプリから呼べません）
9. 「**デプロイ**」をタップ

### 4. 認証（初回だけ）
10. 「**アクセスを承認**」→ 自分のGoogleアカウントを選択
11. 「このアプリは確認されていません」と出たら →「**詳細**」→「**(プロジェクト名)に移動**」
12. 「**許可**」をタップ

### 5. URLをコピーしてアプリに登録
13. 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/........./exec`）をコピー
14. ボートレース予想アプリの **⚙️直前情報サーバー設定**にそのURLを貼り付け

完了です！「予想する」を押すと締切前でも公式から展示を取得して反映します。

---

## 動作確認

ブラウザでこれを開いて JSON が返れば成功です（若松6R・2026-06-13 の例）:

```
https://script.google.com/macros/s/...../exec?jcd=20&rno=6&hd=20260613
```

`{"boats":{"1":{"exhibition_time":6.77,...}},"weather":{...},"exhibition":true}` のように出ればOK。

## うまくいかないとき

- **「アクセスできるユーザー」が「全員」になっているか**を確認（一番のつまずきポイント）。
- コードを直したら、再デプロイは「デプロイ」→「**デプロイを管理**」→ 鉛筆✏️ →
  バージョンを「**新バージョン**」にして「デプロイ」。URL は変わりません。
- それでも反映されない場合は、確認用URLをブラウザで開いて、返ってきた内容を教えてください。
