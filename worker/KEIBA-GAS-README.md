# 競馬データサーバー（Google Apps Script 版）デプロイ手順

**Cloudflare Workers で `HTTP 400` が出る場合はこちらを使ってください。**
netkeiba は Cloudflare のIPからのアクセスを弾くことがありますが、Google Apps Script は
Google のIPで動くため取得できることが多く、確実な代替になります。お持ちの Google
アカウント（追加登録不要）だけで作れます。

`keiba-gas.gs` が netkeiba の公開ページ・オッズを取得して JSON で返す Web アプリです。

> 📱 スマホでも可能ですが、可能なら **PCのブラウザ**だと楽です。
> スマホの場合は Chrome メニューで「**PC版サイト**」にチェックを入れてください。

---

## 手順

### 1. プロジェクトを作る
1. https://script.google.com/ を開く（Googleにログイン済みならそのまま）
2. 「**新しいプロジェクト**」をタップ

### 2. コードを貼り付け
3. 最初から入っている `function myFunction() {}` を**全部消す**
4. `keiba-gas.gs` の中身を**まるごと貼り付け**
5. 💾（保存）で保存

### 3. ウェブアプリとして公開
6. 右上「**デプロイ**」→「**新しいデプロイ**」
7. 歯車⚙️「種類の選択」→「**ウェブアプリ**」
8. 設定：
   - **次のユーザーとして実行**：`自分`
   - **アクセスできるユーザー**：`全員`  ← ここ重要（「全員」にしないとアプリから呼べません）
9. 「**デプロイ**」

### 4. 認証（初回だけ）
10. 「**アクセスを承認**」→ 自分のGoogleアカウントを選択
11. 「このアプリは確認されていません」→「**詳細**」→「**(プロジェクト名)に移動**」→「**許可**」

### 5. URLをコピーしてアプリに登録
12. 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/......./exec`）をコピー
13. 競馬AI予想アプリ（`keiba.html`）の **⚙️データサーバー設定** にそのURLを貼り付け

完了です！「予想する」を押すと、本日のレースとオッズを自動取得して予想します。

## 動作確認

ブラウザで次を開いて JSON が返れば成功です。

**本日の開催一覧:**
```
https://script.google.com/macros/s/...../exec?date=20260613
```
`{"date":"20260613","meetings":[{"place":"東京",...}],"race_count":35}` のように出ればOK。

**1レースの詳細:**
```
https://script.google.com/macros/s/...../exec?race_id=202602010111
```
`{"place":"函館","name":"函館スプリントS","horses":[{"num":3,"name":"レイピア",...}]}` のように出ればOK。

## うまくいかないとき

- **「アクセスできるユーザー」が「全員」**になっているか確認（最大のつまずきポイント）。
- **構文エラー**が出る：スマホのエディタが貼り付け時に記号を壊すことがあります。
  既存コードを**空にしてから**貼る／可能なら**PCのブラウザ**で貼ると確実です。
  最後の行が `function decodeEnt_(s) { ... }` で終わっているか確認を。
- コードを直したら「デプロイ」→「**デプロイを管理**」→ 鉛筆✏️ → バージョン「**新バージョン**」→「デプロイ」。URL は変わりません。
- それでも JSON が返らない場合は、確認用URLをブラウザで開いて、返ってきた内容を教えてください。

## 注意

- netkeiba の HTML/JSON 構造が変わると解析が壊れる可能性があります。
- 取得対象は公開データのみ。常識的なアクセス頻度で利用してください。
